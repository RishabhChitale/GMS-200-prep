# GMS 200 midterm drill

A static quiz site for the GMS 200 midterm (Chapters 1, 7, 2, 8 and 5 of *Management*, 5th Canadian ed.).
It also has a short MTH131 set. Everything runs in the browser from `index.html`; scores and history are kept in your own browser's local storage.

Question sets: slides and notes, the book's self-tests, and a mixed 70-question exam, each with per-option feedback, a timed mode and a score trend.
